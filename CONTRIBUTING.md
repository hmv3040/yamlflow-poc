# Contributing

Start with [the quickstart](docs/QUICKSTART.md), run the demo, and run `make test`.

For a bug report, include your OS/Python version, the command or question that
failed, the expected result, and a minimal reproduction using synthetic data.
Remove credentials and private source data from logs before sharing them.

For a change, explain the problem and behavior in a small pull request. Include
appropriate tests for runtime/compiler changes. Update the quickstart if setup or
expected behavior changes. Edit the YAML source files rather than generated DAGs.

Useful areas for discussion include incremental extraction, relationship checks,
backfill semantics, additional connectors, and agent answer evaluation. These are
ideas, not current capabilities or committed delivery dates.
